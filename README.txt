О ЧЁМ МНЕ ПОВЕДАЛИ ГРИБЫ?

Открыть открытку: дважды нажать index.html. Интернет и установка зависимостей не нужны.

Нажми на обложку или «Открыть книгу». Затем история идёт автоматически:
три разворота по две фразы и заключительная страница с пожеланием счастья.
На каждом развороте своя иллюстрация грибов. Полная история после открытия
занимает около 46 секунд. В конце книга остаётся открытой.

Управление: пауза, стрелки, точки разворотов, «Сначала».
На клавиатуре: стрелки ← →, Escape возвращает к обложке.
На телефоне страницы можно перелистывать свайпом.
При системной настройке уменьшения движения текст появляется сразу,
а страницы переключаются вручную.

Для локального сервера (по желанию):
  python3 -m http.server 4173 --bind 127.0.0.1
Затем открыть http://127.0.0.1:4173

Для будущей записи: http://127.0.0.1:4173/?autoplay=1
Книга сама откроется через две секунды. GIF пока не создавался.

Текст и темп появления: script.js (chapters, firstReveal, secondReveal, pageDuration).
Цвета, размеры и анимации: style.css.

Фон assets/forest.png — первый референс пользователя.
Иллюстрации созданы встроенным image_gen:
assets/mushrooms.jpg — мухоморы, промпт assets/illustration-prompt.txt;
assets/chanterelles.jpg — лисички, промпт assets/chanterelles-prompt.txt;
assets/brackets.jpg — древесные грибы, промпт assets/brackets-prompt.txt;
assets/porcini.jpg — боровики, промпт assets/porcini-prompt.txt.
Шрифт Cormorant Garamond — локальные файлы, лицензия OFL.txt.

Чтобы перенести сайт, нужно скопировать всю папку forest-letter.
